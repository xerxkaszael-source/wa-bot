# Baileys Web Pairing Bot

Node.js + Baileys + Express. Web UI requests a WhatsApp pairing code; no QR is rendered.

## Important limitations
- The code is generated by WhatsApp/Baileys. It is **not guaranteed to be 8 numeric digits**; use the exact code returned by Baileys.
- This is an unofficial WhatsApp Web integration. Use only with your own account and follow WhatsApp terms.
- Render Free does not provide persistent local storage for the auth session. The session can be lost on restart/redeploy. For reliable use, attach persistent storage where available or store auth credentials securely in a persistent external store.
- Keep this app private. Set `PAIRING_TOKEN` in Render Environment to protect pairing/status/reset endpoints.
- Do not upload `auth_info` or API keys to GitHub.

## Run locally
Requires Node.js 20+.
```bash
npm install
npm start
```
Open http://localhost:3000

## Deploy to Render
1. Push this project to a private GitHub repository.
2. Create a Render **Web Service**.
3. Build command: `npm install`
4. Start command: `npm start`
5. Choose Free for testing.
6. In Render Environment, set `PAIRING_TOKEN` to a long random secret (recommended).
7. Deploy, open the service URL, enter your WhatsApp number in international format without `+`, e.g. `628123456789`.
8. On your phone: WhatsApp > Linked devices > Link a device > Link with phone number instead. Enter the code shown on the web page.

## Commands
Send `ping` to receive `Pong! Bot aktif`, or `menu` to see the menu.
